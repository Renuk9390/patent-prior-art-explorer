# Patent Prior-Art Explorer

A small, free, explainable patent semantic search demo — built to
accompany [Renukswamy Chikkamath's](https://your-website-url-here)
PhD research in AI for patent retrieval and explainable prior-art
search.

Search a curated set of real, publicly granted patents by **meaning**,
not just keywords, and see exactly **why** each result matched —
including highlighted evidence sentences, even when the query's exact
words never appear in the passage. Optionally upload your own PDF
(a patent, paper, or technical document) to search it alongside the
demo corpus.

## How it works

```
documents → chunking → embeddings → FAISS vector store → query
    → retrieval → sentence-level explainability / highlighting
    → (optional) LLM plain-language explanation → results
```

- **Embeddings:** `BAAI/bge-small-en-v1.5` — small, free, and fast
  enough to run on a CPU-only Space.
- **Vector search:** FAISS (`IndexFlatIP`, exact cosine similarity) —
  no external database, runs entirely in memory.
- **Explainability & highlighting:** fully local and deterministic.
  Each matched passage is split into sentences, and every sentence is
  scored against the query with the same embedding model — no LLM
  call required for this layer.
- **Optional LLM explanation:** if a `GROQ_API_KEY` secret is set on
  this Space (Settings → Variables and secrets), a short plain-language
  explanation is generated by a free-tier Groq-hosted model on top of
  the embedding-based evidence above. If the key isn't set, or the
  call fails for any reason, the demo silently falls back to the
  embedding-based explanation — this layer is a nice-to-have, never a
  dependency.

See `DOCUMENTATION.md` in this repo for the full architecture writeup.

## Local development

```bash
pip install -r requirements.txt
python app.py
```

Then open the local URL Gradio prints (typically `http://127.0.0.1:7860`).
